# House Price Prediction App

A **Streamlit app** to predict house prices based on area, size, and demographics.  
Supports **India 🇮🇳** and **USA 🇺🇸**, with dropdown inputs for all features.

## Features
- Predict house prices using a trained ML model (`house_model.pkl`)
- Dropdown-based input for:
  - Longitude & Latitude
  - Housing Median Age
  - Total Rooms & Bedrooms
  - Population & Households
  - Median Income
  - Ocean Proximity
- Reasonableness check for predicted prices
- Optional evaluation metrics (MAE, RMSE, R²)
